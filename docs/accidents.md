# 사고접수 및 이력

## 확정 구현 범위 (2026-09-23)

- 활성 회원은 차량을 선택해 사고일, 탑승자, 사고장소, 상황설명을 등록하고 JPG/PNG/WebP 현장 사진을 최대 6개 첨부할 수 있다.
- 차량 선택 시 차량현황의 차량번호, 차종, 본부, 부, 팀, 담당자, 지역을 접수 화면에 표시하고, 접수 당시의 기본정보를 이력에 함께 저장한다.
- 등록된 접수 이력은 활성 회원이 조회할 수 있다. 관리자만 건별 처리 코멘트를 저장한다. 일반회원은 접수·조회만 가능하다.
- 사진은 비공개 `accident-photos` Storage 버킷에 보관하며 로그인한 활성 회원에게만 서명 URL로 제공한다. 파일은 개별 5MB, 총 20MB 이하로 제한한다.

## 서버 적용

`supabase/014_vehicle_accidents.sql`은 `vehicle_accidents` 표, 비공개 사진 버킷, 활성 회원 조회·접수 정책, 관리자 전용 `comment_vehicle_accident` RPC를 만든다. SQL 실행 전에는 화면에서 기존 자료를 불러오거나 저장할 수 없다.

## 운영 기준

- 사고 접수는 삭제·수정 기능을 아직 제공하지 않는다. 원본 접수 내용과 관리자 코멘트를 분리해 이력을 보존한다.
- 차량 기본정보는 사고 접수 당시 스냅샷을 사용한다. 이후 차량현황의 소속·담당자가 바뀌어도 과거 사고 이력은 바뀌지 않는다.
