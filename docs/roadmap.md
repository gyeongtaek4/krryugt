# 개발 진행 상태

갱신일: 2026-09-17. 기존 개발 가이드의 STEP을 기준으로 한다.

## 현재

- STEP 1: 실제 익명 Excel 확인과 계산·권한 규칙 확정 필요.
- STEP 2: HTML 306줄로 분리 완료. 기능별 JS 모듈화·자동 회귀검증은 미완료.
- 이번 작업: 문서 관리 원칙과 주제별 MD 생성 완료. 홈페이지 기능 수정·재검증·배포는 하지 않음.
- 이후 STEP 3~8: 서버 저장·권한, 기본정보, 비용마감, 운행 계산, 보고, 시범 운영 순으로 검토.

## 다음 작업 제안

1. 익명 실제 자료로 키로수 의미·세금·귀속월·조직 이동·평균선·권한 범위를 확정한다.
2. CSV 인코딩 문제를 해결하고 업로드 회귀검증을 마련한다.
3. Supabase 연결 전에 데이터 구조·권한·마감 버전·복원 시나리오를 확정한다.
4. 영구 저장과 관리자 정정, 실제 보고값 연동을 단계적으로 구현한다.

## 실사용 완료 기준

- 두 월 보관, 과거 조회, 정정 원본 유지, 재접속 복원 확인.
- 원본·확정본·대시보드·내려받기 수치 일치.
- 권한 없는 조회·수정 차단과 백업 복구 확인.

기능 요구는 requirements.md, 계산 미결정은 data-rules.md, 오류는 errors.md를 참고한다.
