# 데이터·계산·마감 규칙

기준일: 2026-09-17. 원칙과 현재 구현을 구분한다. 미결정 규칙을 승인 없이 구현하지 않는다.

## 적용할 기본원칙

- 현재 차량·계약·담당자 정보와 월별 확정자료를 분리한다.
- 업로드일과 귀속월은 다르다. 8월 자료를 9월에 올려도 8월 자료로 보관한다.
- 새 월 업로드는 다른 월 확정자료를 삭제하지 않는다.
- 당시 조직정보를 확정본에 보관한다. 늦게 업로드한 과거자료의 조직은 배정 적용기간을 확인한다.
- 비용과 운행 마감 상태는 별도로 관리한다.
- 관리자 정정은 사유·처리자·처리일·버전을 남기고 이전 확정본을 보존한다. 재확정 전에는 직전 확정본을 보고 기준으로 한다.
- 번호는 공백 등을 정규화해 매칭한다. 미매칭·중복·누락은 검토 상태로 표시한다.

## 계산 요구와 미결정

| 항목 | 기준 또는 미결정 |
|---|---|
| 렌트 계약금액 | 계약정보의 월 렌탈료 합계. 유효 계약만 포함할지와 기준일은 추가 확정 필요 |
| 월별 실제 비용 | 해당월 확정 렌탈료·주유비·통행료·주차비. 세금·귀속월·환급 규칙 미결정 |
| 그래프 큰 평균값 | 표시되는 집계값의 평균. 미마감 월을 분모에서 제외하는 방안은 확정 필요 |
| 평균선 | 유지 요구는 확정. 고정 평균인지 이동평균인지 미결정 |
| 증감 | 차액 = 대상월 - 비교월. 비교자료 없음·0원 분모는 별도 상태로 표시하는 방안 |
| 주행거리 | 키로수가 누적값인지 실제 거리인지 확인 후 계산. 월 시작 기준값·계기판 교체 규칙 미결정 |
| 차량 운행일수 | 차량별 실제 운행 확인 날짜 기준 검토. 기록만 있고 거리 변화가 없는 날 처리 미결정 |
| 월중 조직 이동 | 날짜별 배분 또는 대표 부서 기준 미결정 |

미집계와 0원은 구분한다. 기준값 부족을 자동 0km로 확정하지 않는다.

## 현재 구현의 한계

- 브라우저 메모리와 확정 JSON 보관·복원 방식이며 서버 영구 저장이 아니다.
- 현재 거리는 월 내 최대/최소 누적 키로수 차이라 첫 기록 이전 거리를 누락할 수 있다.
- 그래프 선은 현재 3개월 이동평균이다. 최종 의미와 명칭을 맞추는 후속 작업이 필요하다.
- 실제 권한 강제와 배정 적용기간 처리는 후속 개발 대상이다.
