# 디자인 기준

- 차량인수인계의 차량번호·인계일과 차량상태·특이사항은 같은 높이·테두리·모서리·포커스 스타일을 사용한다. 차량번호 입력 중에는 바로 아래에 차량번호·조직·차종 후보를 최대 8개 표시한다. 첫 줄은 차량번호·차량 기본정보, 다음 줄은 인계일·인계자·인수자 3열이며 작은 화면에서는 한 줄씩 표시한다. 특이사항은 필요하면 세로 크기를 늘릴 수 있다.

- 대시보드 순서: 전체 운영차량·렌트 계약금액·6개월 계약만료 요약을 상단 3개 카드로 배치 → 부서별 차량현황 → 확정 운행자료 차량별 이용 순위 → 월별 차량 부대비용 추이·차량 부대비용. 차량별 이용 순위는 이용일수와 월 주행거리 각각의 상위·하위 5대를 두 카드로 나란히 표시하며, 차량번호·팀·집계값의 3열 구성을 사용한다. 부서 목록은 높이 제한·내부 스크롤 없이 모두 펼친다. 작은 화면은 지표를 2열/1열로 배치한다.

- 대시보드 계약 만료 영역은 6개월 내 대상·1개월 내 긴급 수치와 계약정보 보기로 간소화한다. 개별 차량 표는 제거한다.

- 사이드바 하단의 데이터 기준 안내 카드와 접기·고정 제어 버튼은 제공하지 않는다. 사이드바의 접기·펼치기는 상단 메뉴 버튼으로만 조작한다.

- 운행 상단은 운행차량·월 총 주행거리 2개 카드만 표시한다. 본부·부·팀 수는 차량현황의 등록 차량 카드 오른쪽에 작은 배지로 표시하며, 좁은 화면에서는 등록 차량 수 아래로 자연스럽게 줄바꿈한다.

- 운행 월별 보관함은 월 전체거리·확정일을 한 행에 표시한다. 차량별 목록은 월 총거리·고유 날짜 이용일수이며 각 목록에 20행 페이지 이동을 제공한다.

- 차량인수인계는 흰 입력 카드, 민트 사진 영역, 이력 표·사진 상세로 구분한다.
- 인수인계·사고 이력의 상세는 선택한 표 행 바로 아래에 표시한다. 상세 행은 연한 회색 바탕·테두리·여백으로 흰 표 본문과 구분한다.
- 인수인계·사고 이력 상세의 첨부는 작은 카드형 격자로 표시한다. PDF는 큰 미리보기 대신 `PDF / 파일 열기`만 보이는 약 78px 높이의 간결한 카드로 제공하며, 사진도 같은 크기 범위로 맞춘다.
- 사고접수 첫 행은 차량번호 검색 입력과 차량 기본정보, 둘째 행은 사고일과 탑승자로 배치한다. 차량번호 입력 중에는 바로 아래에 차량번호·조직·차종 후보를 최대 8개 표시한다.

## 운행자료 보관 화면 (2026-09-17)

- 상단 요약은 마지막 확정 저장 시각 기준의 월자료를 사용한다. 미확정 업로드·아래 조회월 변경은 요약값을 바꾸지 않는다. 기준월을 별도로 표시한다.
- 화면 진입과 JSON 복원 후 마지막 확정월을 기본 조회한다. 업로드·직접입력 이후에는 검토 대상 월을 조회할 수 있다.
- 보관함 헤더는 흰 배경에서 제목·작은 민트 상태 표시를 나란히 두고 오른쪽에 확정 버튼을 둔다. 큰 그라데이션·단계 문구는 사용하지 않는다. 작은 화면에서는 자연스럽게 줄바꿈한다.
- 보고자료 추출·JSON 보관은 각각 별도 카드로 구분한다. 기존 기능 ID를 유지한다.

## 월별 비용마감자료 (2026-09-17)

- 선택월 비용표 마지막 열은 차량별 총금액이며, 마지막 행은 비용항목별·전체 합계다.
- 보관함의 각 확정월에 조회와 자료 내려받기 버튼을 제공한다.

- 월도·상태 → 자료 준비 → 비용 요약 → 차량별 검토·확정 → 과거 확정자료 보관함 순으로 구분한다.
- 차량·계약 화면과 동일한 흰 카드, 녹색 주요 버튼, 민트 강조를 사용한다.
- 대상 차량 / 렌트비용 / 주유·통행·주차비 / 총 비용을 표시한다. 자료가 없으면 0원 대신 —로 표시한다.
- 파일 선택은 맞춤 버튼으로 제공하며, 백업·복원은 보관함으로 분리한다. 기존 입력 ID와 마감·정정·복원 기능은 유지한다.
- 비용의 서버 저장이 아직 연결되지 않았음을 안내한다. 확정 JSON과 원본 Excel 보관이 필요하다.

차량현황·계약정보는 별도 필터 행 없이 표의 열 제목에서 드롭다운을 연다. 열 제목은 항상 항목명으로 고정한다. 필터 적용 시 은은한 민트 배경과 녹색 글자로 표시하고 선택 목록 첫 항목 '전체'로 해당 필터를 해제한다. 계약 시작/종료·총/남은기간은 각 해당 열에서 함께 선택한다. 필터 초기화는 검색·정보별 선택을 모두 해제한다. 초기화·전체 삭제는 검색창과 같은 목록 상단에 배치한다. 선택 체크박스는 제공하지 않으며 삭제는 행별 버튼과 별도 전체 삭제 버튼으로 제공한다.

- 차량현황·차량계약정보 표는 팀과 담당자(정) 사이에 CC 열을 둔다. 계약 화면의 CC는 차량번호로 연결한 차량현황의 최신 값을 읽기 전용으로 표시한다.

- 차량현황·계약정보 표에서 필터가 있는 열 제목은 아래 데이터와 같은 시작선에 맞춘다. 필터 장식용 내부 여백으로 제목이 오른쪽으로 밀리지 않게 한다.

- 차량현황·계약정보 업로드 안내에는 별도 파일 선택 버튼을 두지 않고 상단 Excel 업로드 버튼만 사용한다. 업로드 팝업의 점선 선택 영역은 전체 너비의 한 카드로 표시하며, 브라우저 기본 파일 선택 입력은 노출하지 않는다.

- 차량현황 상단에는 등록 차량 총합계를 한 번만 크게 표시하고, 그 아래에 팀별·차종별·지역별 차량 대수를 분리한다. 항목과 대수는 연한 회색 배지와 녹색 대수로 구분하며, 표의 검색·필터는 이 요약을 바꾸지 않는다.

- 차량현황의 분류별 차량 대수 배지는 연한 회색 바탕과 녹색 대수로 표시한다. 차량인수인계의 인수자 입력은 이름·이메일 검색 결과를 바로 선택하는 목록으로 제공한다.

- 사이드 메뉴는 대시보드와 법인차량·마감자료·시스템 묶음으로 구분한다. 법인차량에는 차량현황·차량계약정보·차량인수인계를, 마감자료에는 월별 비용마감자료·운행기록데이터를 둔다.

- 상단 종 알림은 화면 하단 토스트가 아니라 종 버튼의 바로 왼쪽 팝오버로 표시한다. 사이드바는 상단 메뉴 버튼으로 접기·펼치며, 펼침 상태는 해당 브라우저에 기억한다.

- 법인차량 묶음의 Q&A와 운행가이드는 흰 카드 목록으로 표시한다. Q&A 답변은 은은한 민트 영역으로 구분하고, 운행가이드는 PDF 열람·다운로드 버튼을 제공한다. 관리자 작성 영역은 관리자에게만 표시한다.

기준일: 2026-09-17. 사용자 요청을 정리한 문서이며 모든 항목의 구현 완료를 뜻하지 않는다.

## 확정된 방향

- 흰 배경의 깔끔하고 장기간 유지보수 가능한 업무 화면.
- 주요 색상 #01916d, 보조 색상 #99d3c5 / #e6f4f0.
- 보조 회색 #adadad / #d6d6d6. 작은 글자는 가독성을 우선한다.
- 메뉴: 대시보드, 차량현황, 차량계약정보, 운행기록데이터, 월별 비용마감자료.
- 공통 데이터 업로드 메뉴와 대시보드 업로드 기능은 제외한다. 각 카테고리에서 입력한다.
- 담당자는 이름만 표시한다. 이름 옆 네모 배지는 사용하지 않는다.
- 버튼 명칭은 양식 내려받기 / 자료 내려받기로 구분한다.
- 운행 입력 화면은 차량별 상세 중심이다. 부서별 운행일수 표시는 제외한다.

## 대시보드

- 전체 운영차량, 렌트 계약금액, 계약만료 대상, 월별 차량 부대비용 추이, 부서별 차량 현황 유지.
- 차량 운영상태, 데이터 완성도, 경영보고서 메뉴 제외.
- 계약만료 예정과 3개월 내 만료를 하나의 영역에서 구분해 보여준다.
- 렌트비용 추이 그래프는 제공하지 않는다. 주유비·통행료·주차비는 항목별 색상을 구분한 선 그래프로 표시한다.
- 선택 월도를 기준으로 최근 3~12개월 범위를 제공한다. 표시 기간은 슬라이더로 조절하며, 기준월에는 부대비용 합계를 표시한다. 미마감 월은 0원이 아닌 미집계로 구분한다.
- 별도 차량 부대비용 요약 카드는 제공하지 않는다.

## 미결정 및 후속 확인

- 평균선은 조회범위의 확정월 전체 평균 고정선이다. 미마감 월은 평균에서 제외하며 0원 막대로 오인되지 않게 표시한다. 상세 계산은 data-rules.md를 따른다.
- 인쇄용 보고서를 제공한다. 용지·페이지 나눔·인쇄 레이아웃은 후속 설계 대상이다.
- 반응형 표의 가로 스크롤, 빈 자료·미매칭·오류·정정 중 상태 표시를 실제 화면에서 점검한다.
- 디자인 요구와 현재 구현의 차이는 requirements.md / roadmap.md에서 관리한다.
