# 차량인수인계

## 현재 구현 (2026-09-17)

- 등록 차량 선택, 인계일, 인계자·인수자, 상태, 특이사항, 외관 사진 기록.
- 인계자는 현재 주 담당자를 기본값으로 제공한다. 저장 시 차량현황 담당자는 자동 변경하지 않는다.
- 상태: 확인 필요 / 이상 없음 / 이상 있음. 자동 판정하지 않으며 이상 있음이면 특이사항 필수.
- 앞·뒤·좌·우와 손상 부위 사진 권장. JPG/PNG/WebP 1~6장, 장당 5MB, 총 20MB.
- 기록 당시 차량·조직·담당자 값을 복사한다. 상세 조회와 사진 원본 내려받기 제공.
- 브라우저 메모리 임시 저장, 사진 포함 JSON 내려받기·복원. 새로고침 시 사라지므로 JSON과 원본을 별도 보관한다.
- 동일 ID·동일 내용은 중복 추가하지 않는다. 충돌 시 전체 복원을 취소한다. 100MB 이하 파일 지원.

## 미구현·다음 단계

- Supabase 인수인계 표·비공개 Storage·RLS·사용자별 권한은 미연결이다. 현재 JSON에는 사진·이름이 포함되므로 회사 승인 위치에 보관한다.
- 인수자 승인·서명, 담당자 변경 연동, 촬영부위별 필수 여부는 후속 협의한다.
- 임시 파일 보관을 회사의 유일한 업무 저장소로 사용하지 않는다.
