# 차량인수인계

## 현재 구현 (2026-09-19)

- 차량번호 직접 입력과 후보 선택, 차량 기본정보(본부·부·팀·차종·담당자(정)·담당자(부)) 자동 표시, 인계일·인계자·인수자, 상태, 특이사항, 외관 사진·PDF 기록.
- 첫 줄은 차량번호·차량 기본정보, 둘째 줄은 인계일·인계자·인수자 3열로 배치한다. 차량번호 입력 중에는 차량번호·조직·차종 후보를 최대 8개 바로 아래에 표시한다.
- 인계자는 차량현황의 담당자와 별개로 사용자가 직접 입력한다. 저장 시 차량현황 담당자는 자동 변경하지 않는다.
- 상태: 확인 필요 / 이상 없음 / 이상 있음. 자동 판정하지 않으며 이상 있음이면 특이사항 필수.
- 앞·뒤·좌·우와 손상 부위 자료 권장. JPG/PNG/WebP/PDF 합계 1~6개, 파일당 5MB, 총 20MB.
- 저장 전 파일 선택을 여러 번 해도 기존 선택을 유지하고 새 파일을 누적한다. 같은 이름·크기·수정시각 파일은 중복 추가하지 않는다.
- 기록 당시 차량·조직·담당자 값을 복사한다. 상세 조회와 첨부 원본 내려받기 제공.
- 이력 상세의 사진·PDF 첨부는 여러 건도 작게 보이는 카드형 격자로 제공하며, PDF는 파일 열기 카드로 표시한다.
- 인수인계 기록은 `vehicle_handovers`, 외관 사진·PDF는 비공개 `handover-photos` Storage에 저장한다.
- 첨부 경로·파일형식과 기록 당시 차량·조직·담당자 스냅샷을 함께 저장하며, 화면 조회 때 1시간 유효 서명 URL을 생성한다.
- 이력 자료 내려받기는 개인정보·사진 URL을 재사용하지 않도록 사진 파일명·크기와 기록 메타데이터만 JSON으로 내보낸다.
- 과거 사진 포함 v1 JSON 불러오기는 화면에서 숨겼고 서버 자료로 자동 이전하지 않는다.

## 인수자 동의 절차 (구현 준비, 2026-09-21)

- 새 기록의 인수자는 이름을 직접 적지 않고 활성 회원 계정에서 선택한다. 이름 또는 이메일을 입력하면 일치하는 활성 회원 계정이 최대 8개까지 나타나며, 선택한 계정으로 로그인한 사람만 인수 동의를 완료할 수 있다.
- 저장 직후 상태는 `인수 동의 대기`다. 지정 인수자가 동의하면 `completed`, 동의 시각과 해당 로그인 계정 ID(`recipient_confirmed_by`)를 함께 저장한다.
- 인계자·관리자 등 다른 계정은 인수 동의를 대신할 수 없다. 화면 이력에는 차량번호 검색과 동의 상태를 제공하며, 상세 화면에서 동의 시각과 마스킹된 동의 ID를 확인한다.
- 계정 지정 기능 이전에 저장된 기록은 삭제·변경하지 않고 이름 일치 여부를 확인한 뒤 인수 동의 대상으로 연결한다. 일치하지 않는 기록은 인수자 계정 미지정으로 보존한다.
- 2026-09-21 실제 프로젝트에서 `supabase/008_handover_recipient_consent.sql` 실행을 완료했다. 활성 회원 목록 호출과 이전 기록 보존을 확인했다.

## 기존 이력의 인수 동의 연결 (구현 준비, 2026-09-21)

- `009_handover_consent_name_and_legacy_match.sql`은 기존 이력의 인수자 이름이 활성 회원의 표시 이름과 정확히 한 명만 일치할 때 그 회원을 인수자로 자동 지정한다. 이후 그 회원에게 `인수 동의` 버튼이 표시된다.
- 이름이 일치하지 않거나 동명이인이면 자동 지정하지 않고 `인수자 계정 미지정`으로 남긴다. 임의의 사용자가 동의하는 것을 방지하기 위한 기준이다.
- 동의 완료 시 당시 동의자의 표시 이름, Auth ID, 동의 시각을 저장한다. 목록에는 동의자 이름, 상세 화면에는 이름·마스킹 ID·시각을 표시한다.
- 2026-09-21 실제 프로젝트에서 009 SQL 실행을 완료했다. 기존 3건 중 활성 회원 이름과 정확히 일치한 2건은 인수 동의 대기로 연결됐고, 일치하지 않은 1건은 자동 연결하지 않았다.

## 작성자·관리자 이력 관리 (구현 및 정책 적용, 2026-09-23)

- 작성자는 본인이 등록한 이력에서만, 관리자는 모든 이력에서 `수정`, `삭제` 버튼을 볼 수 있다. 다른 일반회원에게는 상세 조회와 본인 대상 인수 동의만 제공한다.
- 수정 범위는 인계일, 인계자, 차량 상태, 특이사항이다. 차량번호·인수자·첨부·인수 동의 로그는 감사기록 보호를 위해 수정하지 않는다.
- 삭제는 확인란에 `삭제` 입력 후 진행하며, 기록과 연결된 비공개 외관 사진·PDF를 함께 정리한다. 삭제는 되돌릴 수 없다.
- 2026-09-21 실제 프로젝트에서 `supabase/010_handover_admin_manage.sql` 실행을 완료했다. 2026-09-23 `supabase/017_author_manage_accidents_handovers.sql` 실행으로 작성자·관리자 수정·삭제 RLS로 확장했다.
- 실제 작성자·다른 일반회원·관리자별 수정/삭제와 사진 정리 성공·실패 표시는 운영 전 브라우저에서 별도로 확인한다.
