# Excel 입력 양식

기준일: 2026-09-17. 열 제목은 현재 app.js의 양식 정의 기준이다. 실제 업무 원본은 저장소에 넣지 않는다.

## 첫 행 소제목

차량계약정보 Supabase 업로드: 양식에는 차량번호, 렌탈료, 계약시작, 계약종료만 입력한다. 차량번호는 차량현황에 등록된 번호여야 하며 본부·부·팀·CC·담당자·차종 등 차량 기본정보는 차량현황의 최신 값을 자동으로 사용한다. 렌탈료는 부가세 포함 원 단위 정수다. 동일 차량·시작월·종료월은 기존 계약을 갱신하고 다른 기간은 추가한다. 파일에 같은 차량·기간이 중복되면 저장 전에 차단한다. 파일에 없는 계약은 유지한다.

| 카테고리 | 열 제목 순서 |
|---|---|
| 차량현황 | 본부, 부, 팀, CC, 담당자(정), 담당자(부), 차량번호, 차종, 지역, 주차장 |
| 차량계약정보 | 차량번호, 렌탈료, 계약시작, 계약종료 |
| 운행기록 | 차량번호, 키로수, 운행년월일 |
| 비용마감 | 차량번호, 렌탈료, 주유비, 통행료, 주차비 |

## 입력 안내

- 2026-09-18 변경: 운행은 각 행 이동거리·운행날짜를 입력한다. 같은 차량 여러 행 허용. 한 파일은 한 달 자료. 이전 차량별 월 한 행 안내는 운행 업로드에 더 이상 적용하지 않는다.

- 비용마감 업로드는 차량번호가 차량현황에 등록돼 있어야 한다. 본부·부·팀은 업로드 양식에서 입력하지 않고 차량현황의 최신 정보를 자동 연결한다. 확정할 때 해당 조직값을 비용자료에 함께 보관해, 이후 차량현황 변경으로 과거 확정자료가 바뀌지 않게 한다.
- 비용마감 보관함의 자료 내려받기는 확정월의 조직·차량번호·비용 원본값과 계산한 총금액을 Excel로 제공한다. 마지막 행에는 전체 합계를 넣는다. 업로드 양식에는 본부·부·팀, 계산용 총금액·합계 행을 넣지 않는다.

- 적용: 운행 키로수는 각 행 이동거리, 금액은 부가세 포함이다. 운행년월일의 월로 귀속월을 지정한다. 같은 차량 여러 운행 행을 입력한다.
- 이용일수는 업로드 날짜에서 계산하며 별도 이용일수 열을 요구하지 않는다.
- 첫 행은 위 열 제목을 유지하고 두 번째 행부터 입력한다. 병합 셀과 제목 위 장식 행은 피한다.
- 차량번호는 문자로 입력한다. 매칭 시 공백을 정규화한다.
- 계약 월은 YYYY-MM, 운행일은 YYYY-MM-DD 형식을 권장한다.
- 금액과 키로수는 숫자로 입력하고 원·km 단위 문자는 붙이지 않는 것을 권장한다.
- 계약 총기간·남은 기간은 계산값이며 입력 양식에 추가하지 않는다.
- 운행 귀속월은 운행년월일, 비용 귀속월은 화면에서 선택한 마감월을 사용한다.
- UTF-8 CSV는 BOM 포함을 권장한다. BOM 없는 한글 CSV 문제는 errors.md의 ERR-002 참고.

## 개발 시 점검

- 양식 내려받기 → 익명 자료 입력 → 업로드 → 목록 → 자료 내려받기까지 확인한다.
- 필수/선택 항목, 허용 별칭, Excel 날짜 일련번호, 빈 비용의 0원 처리 정책은 입력 코드와 업무 규칙을 확인한 뒤 확정한다.
- 양식에 작성 안내를 추가하더라도 업로드가 안내 행을 업무자료로 읽지 않게 한다.
