# Q&A · 운행가이드

## 확정된 업무 규칙

- Q&A는 관리자가 질문·답변을 직접 등록, 수정, 삭제한다. 활성 회원은 등록된 내용을 검색·열람만 한다.
- 운행가이드는 관리자가 제목·설명과 PDF 파일 1개를 등록하고 삭제한다. 활성 회원은 PDF를 열람하거나 내려받을 수 있다.
- 운행가이드 PDF는 파일당 최대 20MB이며, 비공개 Supabase Storage에 보관한다. 화면은 열람 때마다 유효 시간이 제한된 URL을 만든다.
- Q&A와 가이드의 관리자 화면 숨김은 편의 기능이다. 실제 작성·수정·삭제 권한은 RLS 정책으로 관리자만 허용한다.

## 저장 구조와 적용 순서

- `fleet_questions`: 질문 제목·내용, 답변, 등록·수정자, 등록·수정 시각.
- `fleet_guides`: 제목·설명, PDF 경로·원본 파일명·크기, 등록자·등록 시각.
- `fleet-guides` Storage: PDF 원본을 비공개로 보관한다.
- 2026-09-21 `supabase/011_knowledge_center.sql`을 실제 SQL Editor에서 실행해 표·비공개 PDF Storage·권한 정책을 적용했다. 관리자 등록·수정·삭제와 일반회원 검색·열람·다운로드의 실제 화면 흐름은 다음 운영 점검에서 확인한다.

## 운영 시 확인할 점

- 가이드 삭제는 목록 기록을 먼저 지우고 연결 PDF를 정리한다. Storage 정리에 실패하면 기록은 삭제되었지만 비공개 고아 파일이 남을 수 있으므로 관리자가 점검한다.
- 업무 원본 PDF, 사용자 이메일 등 민감 자료를 Git 저장소나 MD에 넣지 않는다.
