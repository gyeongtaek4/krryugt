# 개발 검증 체크리스트

이 문서는 점검 기준이다. 체크 항목이 있다는 이유로 검증 완료로 간주하지 않는다.
2026-09-17 리팩터링의 실제 결과와 미확인 범위는 code-structure.md에 보관되어 있다.

## 공통

- [ ] 관련 요구사항과 완료 기준 확인
- [ ] node --check dist/js/app.js
- [ ] node --check dist/js/dialogs.js
- [ ] 실제 브라우저 화면·팝업·콘솔 오류 확인
- [ ] 배포했다면 완료 상태와 배포된 CSS·JS 로딩 확인

## 입력과 내려받기

- [ ] 양식 첫 행 제목, 파일 내용과 날짜·숫자 형식 확인
- [ ] 해당 양식으로 업로드 후 목록 표시 확인
- [ ] 직접 추가·수정, 미매칭·빈 값·중복·잘못된 날짜 확인
- [ ] 자료 내려받은 파일 내용과 화면 합계 일치 확인

## 월별 마감과 보고

- [ ] 서로 다른 두 월 자료를 올려 기존 월 유지 확인
- [ ] 대상 월 과거 조회와 확정 상태 확인
- [ ] 정정 전 확정본 유지, 사유 기록, 재확정·버전 조회 확인
- [ ] 재접속 후 JSON 복원 또는 서버 저장 복원 확인
- [ ] 현재 조직 변경 후 과거 보고 유지 확인
- [ ] 계약합계, 그래프 평균, 월경계 거리, 미집계와 0원 구분 확인
- [ ] 실제 권한 연결 후 허용·차단 모두 확인

## 작업별 결과 기록

날짜 / 작업·커밋 / 환경 / 익명 샘플 / 실행 항목 / 결과 / 미검증 범위 / 후속 작업을 기록한다.
문법 통과, 화면 표시, 다운로드 안내만으로 전체 기능 또는 저장파일 검증을 대신하지 않는다.
